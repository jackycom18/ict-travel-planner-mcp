# MCP 智能行程规划设计

> 目标判据：华为 ICT 1.7 实验手册与用户“只使用免费资源”的约束。

## 目标

交付一款可直接运行的南京三日旅行攻略应用，包含三天气象、每天三个景点、同城打车段、路线图和旅行贴士。应用同时支持高德 Key 配置，并在没有 Key 时使用完整离线演示数据，确保零费用和可验证性。

## 页面结构

- 顶部：日期、城市、行程概览和 AI 规划摘要。
- 气象栏：5 月 1 日至 3 日的气温、天气和穿衣建议。
- 行程区：按天切换，每天展示 3 个景点卡片和 2 段打车信息。
- 地图区：本地 SVG 绘制南京城市轮廓、河流、路线和景点标记；点击景点会高亮对应地图点。
- 贴士区：交通、预约、天气与用餐建议。

## 视觉方向

- 基调：金陵手账 + 现代编辑设计。
- 色板：宣纸白 `#f4f0e7`、墨黑 `#1e2724`、城墙红 `#b94a3e`、秦淮青 `#457b76`、暖金 `#d8aa58`。
- 排版：宋体风格标题与清晰的无衬线正文，强调日期和地点的信息层级。
- 结构：不使用统一卡片网格；地图与日程形成主次分明的双栏布局。

## 数据与 MCP

- 内置 2026-05-01 至 05-03 的南京行程与示例天气。
- 景点坐标用于本地路线图。
- 提供 `.codeartsdoer/mcp/amap/.env.example` 和 `mcp_settings.example.json`，用户可选择配置自己的高德 Key。
- 不把真实 Key 写入页面、代码或 Git。

## 文件结构

- `index.html`：应用结构、内联 SVG 和内容入口。
- `styles.css`：完整视觉与响应式布局。
- `app.js`：行程数据、按日切换、地图高亮与天气渲染。
- `test-ui.py`：Playwright 浏览器验收。
- `mcp_settings.example.json`：高德 MCP 配置示例。
- `README.md`、`docs/`：运行、MCP 配置与交接说明。

## 验证

- 页面显示三天天气和 9 个景点。
- 每天恰好 3 个景点和 2 段打车。
- 切换日期后景点、路线和地图标记同步变化。
- 点击景点会高亮地图标记。
- 页面在桌面和手机宽度下无横向溢出。
- 不含真实高德 Key，页面运行无脚本错误。
